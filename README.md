# [W5500] RJ45 Tester для Flipper Zero

Тестер Ethernet-розетки и порта коммутатора на Flipper Zero с модулем
WIZnet W5500. Подключается так же, как [W5500] Ethernet, поэтому собранный
модуль переставлять не нужно.

Что показывает и умеет:

- **Состояние линка** в реальном времени (опрос каждые 20 мс): есть линк или
  нет, скорость 10/100, полный или полудуплекс, сколько длится текущее
  состояние; сколько раз линк падал, сколько длился последний простой и все
  вместе; смена скорости или дуплекса на лету.
- **Журнал событий** с временем: линк поднялся или упал (и на сколько),
  DHCP, конфликт IP, соседи, результаты пинга, DNS и сканов. Пишется ещё и на
  SD-карту — `apps_data/rj45_tester/log.txt` — с датой, чтобы потом
  разобраться, когда и что падало.
- **Звук, вибро и светодиод** при падении и подъёме линка: можно воткнуть
  кабель, отойти и шевелить его в патч-панели.
- **DHCP**: адрес, маска, шлюз, DNS, какой сервер выдал, сколько длилась
  выдача и сколько осталось аренды; продление на половине срока. Можно задать
  статический адрес.
- **Поиск DHCP-серверов**: отправляет DISCOVER и показывает **все** серверы,
  которые ответили, — так находится чужой («левый») DHCP. Адрес при этом не
  занимается.
- **Коммутатор (LLDP / CDP)**: имя коммутатора, порт, описание порта,
  VLAN порта, голосовой VLAN, адрес управления, что коммутатор думает о
  скорости и дуплексе на своей стороне (с предупреждением о
  **несовпадении дуплекса**), PoE (класс и выделенная мощность).
- **STP**: корневой мост (приоритет и MAC), стоимость пути; **802.1Q** —
  какие VLAN-теги приходят в порт (видно, что порт транковый).
- **Ping**: шлюз, DNS, 8.8.8.8, 1.1.1.1 или любой адрес; потери, min/avg/max,
  график последних 32 ответов; отдельно «нет ответа ARP», «недоступен» и
  «TTL истёк».
- **DNS**: разрешить имя и время ответа.
- **Узлы в сети (ARP)**: сканирование подсети (до /22, больше — только своя
  /24) с MAC-адресами, плюс узлы, услышанные пассивно по ARP. Отмечены свой
  адрес и шлюз.
- **Конфликт IP**: W5500 сам сообщает, если кто-то ещё отвечает на наш
  адрес, — запись в журнале и сигнал.
- **Трафик**: сколько кадров видно на порту, широковещательные и групповые,
  ARP / IPv4 / IPv6, пик кадров в секунду; предупреждение о
  **широковещательном шторме** (больше 300 кадров/с).
- **Wake-on-LAN**: разбудить компьютер по MAC (кадр 0x0842, работает и без
  IP-адреса).
- **Настройки**: DHCP или статический адрес, режим линка (авто, 100/10,
  полный/полудуплекс — принудительно, чтобы проверить, держит ли кабель
  100 Мбит), MAC (постоянный от Flipper, случайный или свой), звук, вибро,
  5 В на выводе 1, запись журнала на SD.

Чего W5500 не умеет, а потому нет и здесь: 1 Гбит/с (у W5500 только 10/100),
длина кабеля и место обрыва (TDR), проверка пар по отдельности, PoE на
стороне Flipper. Скорость передачи данных через Flipper упирается в SPI
(около 1–2 Мбит/с), поэтому замера пропускной способности нет — «скорость» здесь
это согласованная скорость линка.

## Подключение

| W5500 | Flipper Zero |
|---|---|
| MOSI | A7 (вывод 2) |
| MISO | A6 (вывод 3) |
| CS / nSS | A4 (вывод 4) |
| SCK | B3 (вывод 5) |
| RST | C3 (вывод 7) |
| GND | GND (вывод 8 или 11) |
| 3V3 | 3V3 (вывод 9) |

Модулю с питанием 5 В — вывод 1 (5V). Если модуль не найден и 5 В
выключено, на первом экране будет кнопка **Enable 5V** — нажать OK. Настройка
запомнится, и при следующих запусках 5 В включится само. Выключить —
«Settings → 5V on pin 1».

## Установка из готового пакета

Пакет `.fap` собирается автоматически при каждом пуше (GitHub Actions) под три
прошивки. Брать файл под **свою** прошивку — у них разные версии API, чужой
файл не запустится («API mismatch»):

| Прошивка | Файл |
|---|---|
| Официальная | `rj45_tester-official.fap` |
| Unleashed | `rj45_tester-unleashed.fap` |
| Momentum | `rj45_tester-momentum.fap` |

Собирается под последний **выпуск** (release) каждой прошивки. На dev- или
старой версии прошивки может не запуститься — тогда обновить прошивку или
собрать самому (ниже).

1. Скачать файл:
   - **Releases** → «Свежая сборка» (`latest`) — последний коммит основной
     ветки: <https://github.com/pmmodlin/rj45-tester/releases/tag/latest>;
     выпуски с номером (`v0.1.0` и т. д.) — там же, в Releases;
   - или **Actions** → нужный запуск → внизу раздел *Artifacts* (нужно войти
     в GitHub; файл придёт в zip, внутри `.fap`).
2. Положить на SD-карту Flipper в `apps/GPIO/` (имя файла можно оставить
   как есть):
   - **qFlipper**: подключить Flipper по USB → вкладка *File manager* →
     `SD Card/apps/GPIO` → перетащить файл;
   - **lab.flipper.net** (Chrome/Edge): подключить по USB → *Archive* →
     `apps/GPIO` → загрузить файл;
   - **мобильное приложение Flipper**: *Archive* → `apps/GPIO` → загрузить;
   - или вынуть SD-карту и скопировать в `apps/GPIO/` на компьютере.
3. На Flipper: **Apps → GPIO → [W5500] RJ45 Tester**.

Обновление — то же самое, новый файл поверх старого. Настройки и журнал
лежат в `apps_data/rj45_tester/` и при обновлении сохраняются.

## Управление

- Приложение открывается сразу на экране линка; **Назад** — меню.
- **Вверх / вниз** — прокрутка (в журнале «вверх» — к старым записям).
- **OK** на экране:
  - «Link status» — запросить адрес по DHCP заново (при статическом —
    переприменить настройки);
  - «Ping» — старт/стоп; **вправо** — сменить цель, **влево** — ввести свой
    адрес;
  - «DNS lookup» — разрешить имя; **влево/вправо** — ввести имя;
  - «Hosts (ARP scan)» — сканировать подсеть;
  - «DHCP servers» — найти все DHCP-серверы;
  - «Traffic» и «Switch / LLDP / CDP» — сбросить счётчики, соседей и STP;
  - «Wake-on-LAN» — отправить; **влево/вправо** — ввести MAC.
- Настройки применяются при выходе из «Settings» (W5500 перезапускается,
  линк поднимается заново).

LLDP/CDP коммутаторы шлют раз в 30–60 секунд — сведения о порте появляются
не сразу. Неуправляемые коммутаторы их не шлют вовсе.

Интерфейс на Flipper — по-английски: штатные шрифты прошивки не содержат
кириллицы.

## Сборка самому

```sh
pip install ufbt
ufbt update                     # официальная прошивка
# ufbt update --index-url=https://up.unleashedflip.com/directory.json      # Unleashed
# ufbt update --index-url=https://up.momentum-fw.dev/firmware/directory.json  # Momentum
ufbt                            # пакет — dist/rj45_tester.fap
ufbt launch                     # собрать, залить по USB и запустить
```

Свой выпуск с номером: заметки — в `release-notes/vX.Y.Z.md`, версия — в
`fap_version` в `application.fam`. Затем либо **Actions → Build → Run
workflow**, в поле «Тег выпуска» — `vX.Y.Z`, либо `git tag vX.Y.Z && git push
origin vX.Y.Z`. Actions соберёт, создаст тег и выложит файлы в Releases.
